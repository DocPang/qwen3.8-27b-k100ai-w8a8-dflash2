## 0. 口径声明

- `tps` = 服务端输出 token/秒（**双卡合计**）；`每卡` = `tps / 2`。
- `TTFT` / `TPOT` 按官方要求取**均值**（各正式轮次逐请求均值的再平均）。
- `相对基线` = 本方案 tps ÷ 官方 K100_AI / SGLang 0.5.12 同档基线（平均值）。
- 4K/1K：2 轮预热 + **3 轮**正式，每轮 `max(8, 2×C)` 请求，固定随机 token id（seed 20260912）。
- 64K/1K：1 轮预热 + **2 轮**正式，同上。
- ShareGPT：`ShareGPT_V3_unfiltered_cleaned_split.json`，每档 **1000 条**，warmup `2×C`，`request-rate=inf`，单轮。
